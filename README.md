# daily-papers

每日论文精选

A daily selection of papers.

惊霓日录 · Jingni Daily

</div>

一天一篇，新的写在最上面。只留值得留下来的，同一天同一个链接只出现一次。

One file a day, newest first. Only what is worth keeping. The same link appears once on a given day.

## 关于 · About

只收当天核过、值得留下的论文。综述、方法、研究和轻观点都可以，但没进日选的标题不进这本。

Papers that cleared the day's selection. Surveys, methods, studies, and lighter notes all qualify. A title that was not selected stays out.

## 一条里有什么 · What one entry holds

| 字段 Field | 写什么 |
| --- | --- |
| 日期 Date | `YYYY-MM-DD` |
| 标题 Title | 原文标题，必要时补一句中文 |
| 链接 Link | 原文地址 |
| 为什么留 Why | 一句，说清它为什么在这本里 |

正文在 [entries](entries)。空页是 [entries/_template.md](entries/_template.md)。

## 不收 · Left out

机构新闻、转述、仓库和访谈不进这本。

Institutional news, retellings, repositories, and interviews stay out.
